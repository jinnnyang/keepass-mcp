# 0001 密钥边界模型：创建可写、读改需审批、明文永不外泄

- Status: accepted (2026-10-01)

初版设计把"保护字段对 Agent 不可见、不可操作"设为绝对边界；经访谈澄清，用户需求是"创建新条目时可写入密钥；读取/修改已有密钥需额外审批；任何读出口不得直接暴露保护字段明文"。因此采用三态模型：① `create_entry` 可携带保护字段值（Agent 传值或插件内 `generate_password` 生成），免审批；② `read_secret` 与修改已有保护字段需密钥访问审批（机制见 ADR-0002）；③ 不变量：工具返回/资源/审计/备份永不含保护字段明文，禁止把保护字段值复制进可见字段（以 schema 排除 + 全审计实现，不做值内容比对）。

后果：`read_secret` 审批通过后明文会进入 Agent 上下文一次（用户已明确接受）；审计是唯一追溯手段，故读取必须逐字段记录。被否决方案：无约束读取（摧毁掩码边界）、纯元数据管理（不满足"存取密钥"需求）。
