# 0002 审批机制：密钥访问白名单 + KeePass UI 弹窗组合

- Status: accepted (2026-10-01)

"额外审批"有请求参数确认、预授权、UI 弹窗三种实现形态。选定组合方案：密钥访问白名单（按条目 UUID 配置）内的条目免审批直接访问，全程审计；白名单外条目由插件在 KeePass 主窗口弹确认框（显示库/条目/字段/操作类型），默认 60s 超时按拒绝处理，拒绝与超时均不返回明文。弹窗必须经 UI 线程 marshal（KeePassLib 非线程安全，HANDOFF §2）。

后果：白名单是"免审批"的唯一豁免通道，需在插件选项页可增删；弹窗审批依赖 KeePass 前台交互，Agent 自动化场景下非白名单请求会阻塞等待或被拒。
